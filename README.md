OVH SDK
=======

An unofficial, modern PHP SDK for the [OVHcloud API](https://api.ovh.com/), built on top of [Saloon](https://docs.saloon.dev/), with built-in Laravel integration.

> **Work in progress:** this package is under active development and is not ready for use yet.

Goals
-----

* Fluent, typed resources returning immutable DTOs
* Modern PHP (8.4+)
* Easy testing with Saloon's mocking tools
* Framework-agnostic core, with optional Laravel integration in the same package

Requirements
------------

* PHP 8.4 or higher
